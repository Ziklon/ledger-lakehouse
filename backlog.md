- [x] gate-iceberg-commit-race - fix(gate): wait for an Iceberg commit after the sink offsets catch up (kind: ship) (priority: 1) (done 2026-11-03)
  Iceberg sink 1.12.0 commits SOURCE offsets (group connect-bronze-sink) in the worker's Kafka transaction with DATA_WRITTEN (Channel.java:97-106), BEFORE the coordinator's Iceberg commit (Coordinator.java:200-211). gate.py check 2 reads that group, so it can pass while rows are not yet visible in bronze. Events committed just before the cut-off would then be missed by day N and by day N+1 (its window starts after them): silently lost from silver/gold. Fix: after wait_for_sink passes at T, wait for a heartbeat with _source_commit_ts > T visible in bronze (a later commit cycle implies ours; failed cycles roll responses forward). Cost: up to one commit interval. Also correct ADR 0010 and gate.py docstring; add a test showing the current gate passes early.
